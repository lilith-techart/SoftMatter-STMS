## Findings without euphemisms

1. **Material microstructure target — NOT MET.** Product-distance micro-contrast 0.0011–0.0017; macro 0.00063–0.00096, below the 0.0010 acceptance threshold for all eight macro candidates. A new authored micro-surface route is required before claiming close-up detail quality.
2. **Local contact visual read — FAIL.** Input pressure 0→0.45; authored contact depth 0→0.0293, but projected body count remains 233,225 across the measured 151 frames and 141/150 successive pairs are byte-identical. The physics/control path is not a satisfying visual press.
3. **Damage and return — PARTIAL.** Actual continuous render, deterministic return; weak state transition and no coloured bruise term. Haze/thinning alone does not fully read as tissue damage.
4. **Soft fracture — VISUAL LIMITATION.** One mesh remains; no true physical/topological tear. The visible gap is not a complete separation, and single-pass transparency sorting limits readability.
5. **Formation — CONCEPT PARTIAL / NOT ACCEPTED.** A study distinct from regeneration; must not be described as a shipped growth capability.
6. **Preset gallery — ENGINEERING VALIDATED.** Profiles unchanged, multiple deterministic views; two clear identities are still visually close at Hero distance.
7. **Performance — GPU UNMEASURED.** CPU submission and read-back synchronization are measured, not equivalent to frame rate or GPU timings.
8. **Regression — OPEN.** 19/19 historic collectors ran clean, but 66 locked rendered file outputs were not byte-identical; no blanket historical-regression PASS.
